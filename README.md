# Acumulo-de-Patrimonio
Simulador de Investimentos em FIIs no Excel.

- Arquivo: Jc_Invest.xlsx 

---

Consegui executar com êxito essa ferramenta que faz todos os cálculos e simula muito bem investimentos financeiros.

# O que é a ferramenta?
É uma planilha no Excel de simples de usabilidade e de grande eficácia, direta ao ponto sem complexidade.

# O que tem na ferramenta?

- Escolha entre diferentes perfis de investidores: Conservador, Moderado e Agressivo;
- Diferentes tipos de FIIS: Papel, Tijolo, Híbrido, FOFs, Desenvolvimento e Hotelárias.
- Cálculo de sujestão de investimento com estimativa de 30% do salário informado.
- Estimativas de rendimentos em diferentes cenários.
- Tenha todo o controle ao alcanse com facilidade, rapidez e confiança.
